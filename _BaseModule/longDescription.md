# Italian Vanilla Theme Overrider 
## SERIE A PACK

Hello and Ciao. This is a Vanilla Theme Overrider that turns Vanilla Signs and Roadmarkings to Italian ones.
This Overrider uses the Traffic Type Spain Font. Can be found [here](https://www.onlinewebfonts.com/download/f820971323ed634d5ef50513e34fbd3c).
